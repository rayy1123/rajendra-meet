# PANDUAN PENYIMPANAN ASSET VIDEO RAJENDRA MEET

Letakkan berkas video dokumentasi kejuaraan renang di folder ini:

1. Video Utama:
   - Nama File: community-video.mp4
   - Format: MP4 (H.264 / AAC)
   - Resolusi Disarankan: 1920x1080 (16:9 Landscape) atau 1080x720
   - Ukuran Maksimal Disarankan: < 25 MB (untuk loading web cepat)

2. Poster Thumbnail Video (Gambar Sampul Sebelum Video Diputar):
   - Nama File: community-poster.jpg
   - Format: JPG / PNG / WebP
   - Resolusi: 1920x1080 (16:9)

Catatan:
Jika berkas video belum diletakkan di folder ini, sistem secara otomatis
menampilkan gambar poster fallback dari `/brand/community-team.png` sehingga
tampilan website tetap aman, tidak rusak, dan rapi.
