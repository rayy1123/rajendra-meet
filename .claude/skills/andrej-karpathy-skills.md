# Andrej Karpathy Engineering Philosophy

First-principles thinking, crystal-clear mental models, and deep mechanical sympathy.

## Core Mantras
1. **Understand Everything from Scratch**:
   - Don't just import bloated abstractions when 20 lines of clear, self-contained TypeScript solves the problem cleanly.
   - Know what every line of code does under the hood (memory allocations, database queries, DOM paints).
2. **Zero Magic / Mechanical Sympathy**:
   - Prefer transparent, readable data pipelines over hidden metaprogramming and convoluted middleware magic.
   - Algorithms (Spearhead seeding, Circular prelims, FINA point matrices) must be written with mathematical clarity.
3. **Write Runnable Checks**:
   - Every non-trivial algorithm must have runnable unit tests asserting edge cases, invariant preservation, and exact numerical outputs.
4. **Iterate in Small Steps**:
   - Build a minimal working baseline first. Test it thoroughly. Layer optimizations only when verified.
